🧠 How to Identify This Pattern

🪟 Sliding Window Trigger Words

When you see these in a problem statement, think Sliding Window immediately:


longest subarray/substring shortest subarray contiguous at most K distinct no repeating sum ≥ target max sum of size k

📐 3-Question Checklist

1. Is the answer a contiguous subarray/substring?
2. Can you define a "valid window" condition?
3. Does expanding/shrinking one end make sense?


If all 3 are YES → Sliding Window.

⚡ Complexity Cheat

Brute Force: O(n²) or O(n³)
HashSet Window: O(n) — each char added/removed once
HashMap Optimized: O(n) — j jumps directly, no inner loop

📊 Approach Comparison

① HashSet + Two Pointers

Move i forward always. When duplicate found, shrink from j until clean. Set stores current window chars. Simple and intuitive.

② HashMap (Last Index)

Store last seen index of each char. When duplicate found, jump j directly past the old occurrence — no inner loop needed. Fastest in practice.

③ Brute Force

Try every possible start index i. For each, expand j until duplicate found. O(n²) — fails for n > 10⁴ in interviews. Shows you understand it but never submit this.

🎯 Interview Tip

Always start with brute force (shows thinking), then say "We can optimize this to O(n) using a sliding window…" — that's the 10 LPA move.
